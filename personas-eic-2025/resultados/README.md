# Resultados reproducibles

- `resumen.json`: universo y cada estimación puntual, porcentaje y precisión aproximada.
- `indicadores.csv`: vista tabular de los mismos indicadores para Excel, Python o R.
- `auditoria.json`: segunda agregación independiente de las cinco conclusiones del informe.

Los intervalos identificados como `aproximada_no_oficial` son estimaciones exploratorias del script. Para intervalos de indicadores publicados, consulte las filas 7663 a 7665 del [Excel oficial del INEGI](https://www.inegi.org.mx/contenidos/programas/eic/2025/microdatos/eic2025_micro_105.xlsx). La ruta exacta de celdas se documenta en [`FUENTES_INEGI.md`](../FUENTES_INEGI.md).
